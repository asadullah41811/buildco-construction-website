# Build CO — Construction Company Website

A modern and responsive construction company website designed to showcase construction services, completed projects, and professional expertise. Built using HTML5, CSS3, and Bootstrap.

## 🚀 Features

* Responsive navigation bar
* Attractive hero section
* Professional services cards
* Construction project showcase
* Client testimonials section
* Modern footer design
* Responsive layout for mobile, tablet, and desktop
* Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and customization
* **Bootstrap** — Responsive layout and UI components

## 📂 Project Structure

buildco-construction-website/

## 💻 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/buildco-construction-website.git
   ```

3. Open `index.html` in your browser.
